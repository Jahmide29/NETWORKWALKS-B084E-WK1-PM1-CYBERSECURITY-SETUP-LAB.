🔶️ Step by step setup of a  virtual Cybersecurity Lab for Pentesting and Networking projects. 

# 🔶️Project Overview:
This project focus mainly on setting up a virtual lab, configuring and testing network connections. 

The lab is configured on a private virtual network where it is safe,secured and can accommodate other  virtual machines.

# 🔶️Purpose of the lab:

The lab configured here is mainly used for:
   
    ◇ Network reconnaissance
   
    ◇ Port Scanning 
   
    ◇ Exploitation practices
   
    ◇ Web testing.

# 🔶️LAB CONFIGURATION 


* Host OS --->>> Windows 11

* Host RAM --->>> 8 GB 

* Host Processor --->>> Core i5

* Hypervisor --->>> Virtual Box 7.2

* Security OS --->>> 2026.2

* Kali RAM --->>> 4096 MB

* Virtual Network --->>> NAT Network 

* Network Address --->>> 10.0.0.2

* Kali Address --->>> 10.0.0.1

* DNS Server --->>> 8.8.8.8 


# 🔶️LAB SETUP PROCEDURES:

1. Install 7-zip for file extraction.

2. Install Virtual box

3. Create the NAT Network to allow multiple machines to connect to each other

4.Install Kali Linux and import it. Then configure the network adapter and allocate a RAM atleast 2048 MB.

5. Configure the kali linux network it's address and subnet mask etc. giving it a consistent or static IP.

6. Then create a clean snapshot VM for future recovery in case of damage.
